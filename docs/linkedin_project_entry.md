# LinkedIn Project Entry

## Project name

FahMai RAG Challenge – Super AI Engineer Season 6

## Description

Built a retrieval-augmented generation (RAG) pipeline for Thai product-support question answering using a knowledge base of product pages, store policies, and store information.

The system retrieves relevant evidence from Thai documents, compares retrieved content against 10 multiple-choice answer options, and selects the most evidence-supported answer. It also handles special answer classes such as “no data available in the knowledge base” and “question unrelated to FahMai store.”

Achieved a perfect score of 1.00 and ranked 17/341 participants.
